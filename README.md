# University Service Navigator

## 📌 Project Overview

University Service Navigator is a web-based platform designed to help university students easily find and access official university services.

The system provides clear and organized information about university services, including required documents, procedures, responsible departments, locations, working hours, fees, and official service links.

## 🎯 Project Objectives

* Simplify access to university services.
* Reduce confusion about university procedures.
* Provide accurate and organized service information.
* Help students find the right department and location.
* Improve the overall student experience.

## 👥 User Roles

The system has three main user roles:

### 1. Student

* Search for university services.
* Browse services by category.
* View service details.
* Find departments and locations.
* View required documents and procedures.
* Save favorite services.
* Report incorrect information.

### 2. Administrator

* Add new services.
* Update service information.
* Deactivate obsolete services.
* Manage service categories.

### 3. University Staff

* Review and verify service information.
* Submit service information updates.
